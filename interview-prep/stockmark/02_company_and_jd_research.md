- 資金: 2024年10月 シリーズD 45億円（累計88億円）
- ミッション: 「価値創造の仕組みを再発明する」。ブランド約束「シゴトを楽しくするAI」
- 認証: ISO 27001 / 27017
- 直近の方向性: FDE（Forward Deployed Engineer）採用の拡大、大手16社との「AI-Ready化」プロジェクト

## 2. プロダクト（面接で必ず語れるようにする）

### SAT（Stockmark A Technology）— PaaS
- 「業務AIの実装支援プラットフォーム」。非構造データの構造化 → RAG/エージェント構築 → 業務実装まで
- 搭載技術（求人票の記載）: Agentic RAG、Agentic OCR、Deep Research、ナレッジグラフ
- SAT Division の体制: ビジネス側 20名（戦略・ITコンサル出身）、テクノロジー側 28名（NLP/CV の R&D エンジニア、FDE、Web アプリエンジニア、SRE）
- 谷本氏（SAT Tech Unit Leader）の発信: 「RAG 構築におけるデータ構造化の4つのポイント」。ハルシネーション対策 = 検索精度 = ドキュメント構造化という思想
- NLP チーム（Tommy Gunawan リード）: エンタープライズ向け Agentic 検索、GraphRAG、エビデンスチェック、検索基盤
- 構造化チーム（榊原氏リード）: ドキュメント構造化（図面・帳票・技術文書）
- FDE: 「AI-Ready プロジェクト」で企業の暗黙知を形式知化。個別開発した機能のうち汎用的なものをプロダクトへ還元するサイクルがある

### Aconnect — SaaS
- 製造業 R&D 向け AI エージェント。情報収集 → 知識化、リスク/機会検知
- 2026年のリリース: 特許調査エージェントの EPO 対応（4/30）、技術探索エージェント「解決策比較β」（5/20）、「発想のヒント β」（7/23）、「ツリーの共有・コメント機能」

### Stockmark-2（自社 LLM）
- 1,000億パラメータの日本語特化 LLM（2024年5月公開）。「自社管理下で安全に運用可能」「ハルシネーションを大幅に抑制」が訴求点
- Research Division の成果（Tech Blog より）:
  - Stockmark-DocReasoner-Qwen2.5-VL-32B（日本語ドキュメント読解 CoT モデル、HF 公開、2026-04）
  - OmniDocBench-JASyn（日本語文書画像構造化ベンチマーク、2026-05）
  - ACL 2026 Industry 採択「LLM-as-a-Judge に唯一の正解を求めすぎていないか」（評価の多様性、2026-06）
  - Nemotron-3-Nano-Omni への日本語文書構造化 post-training（2026-07）

## 4. JD 1196: Applied Research Engineer（AIエージェント研究開発 / 顧客実装）

### ミッション
研究成果を「エンタープライズ顧客の業務で価値を発揮するプロダクト」へ昇華させる。先端 AI/NLP とビジネス実装の結節点。

### 業務内容
- AI エージェントの開発・改善（中核ロジックの高度化）
- 初期価値検証 PoC の設計・実行
- 精度評価基盤の構築
- 顧客要件に基づくカスタマイズ
- PoC → 継続的改善までのサイクル全体をオーナーシップを持って推進
- リサーチャー・PM・コンサルタントと連携し、顧客課題を技術要件に落とし込む

### 必須要件 → 自分の対応（面接で明示的に結びつける）
| 要件 | 自分の根拠 |
|---|---|
| AI/NLP/ML 領域の研究経験（大学院またはビジネス R&D） | 楽天証券での金融ドメイン LLM ファインチューニング、SoftBank での LLM 評価基盤（ビジネス R&D として語る） |
| 生成AI（LLM/RAG/エージェント）の知識と実装経験 | SoftBank: RAG/エージェント設計の標準化。楽天証券: RAG 投資 QA（GCP）。Canlah.AI: K8s 上のマルチエージェント SaaS を本番運用 |
| Python での実験設計・評価・プロトタイピングを自律的に遂行 | LLM 評価基盤の構築、A/B・オフライン評価の設計 |
| 技術検証結果を顧客価値から評価し次アクションに繋げる | PoC → 本番までやり切った経験、ステークホルダーとの合意形成 |

### 歓迎要件 → 対応
- 論文執筆・学会発表: なければ「社内技術発信・ブログ・勉強会」で代替を語る（正直に）
- LLM エージェントのワークフロー設計・評価の実務: Canlah.AI と SoftBank の事例
- 顧客折衝を伴う PoC・R&D 推進: SoftBank 社内顧客（事業部門）との PoC
- 統計モデリング・ベイズ推定: 触れられる範囲で（誇張しない）
- 研究成果のプロダクト化: 楽天証券の RAG 投資 QA を本番提供

### 求める人物像（面接官が見るポイント）
1. 研究の面白さと事業インパクトの両立を重視
2. 第一線のリサーチャーと対等に議論できる技術的素養、論文以上の価値創出志向
3. 曖昧な要件でも仮説検証を自ら設計して推進できるオーナーシップ
4. 顧客現場の声から技術課題を発見することにやりがい
